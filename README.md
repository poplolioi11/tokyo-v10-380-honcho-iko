# 本朝醫考 · 東京大學藏本 V10:380

《本朝醫考》由黑川道祐編纂，分上、中、下三卷，以漢文記日本古代醫事、歷代醫家傳記、醫官制度、方技傳承和書目。東京大學藏本有原刻送假名、返點與補鈔總目錄。序署寬文三年（1663），刊記題田原仁左衛門，刊年原書未記。

The three-volume Honchō ikō, compiled by Kurokawa Dōyū, supplies biographies and institutional history of medicine in Japan. This edition follows Tokyo University General Library V10:380. The 1663 date belongs to the preface. All 113 manifest frames are indexed. The release includes a transcription of the printed text, manuscript table of contents, and visually read marks with their uncertainties.
